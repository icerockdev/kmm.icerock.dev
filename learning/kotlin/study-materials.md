## Книги

- [Kotlin in Action, Second Edition](https://www.manning.com/books/kotlin-in-action-second-edition) — для людей с Java опытом. Второе издание (2024) от разработчиков языка, охватывает Kotlin 2.0, корутины и flows
- [Effective Kotlin](https://kt.academy/book/effectivekotlin) — для людей уже с опытом в Kotlin. Лучшие практики и идиомы языка
- [Kotlin Essentials](https://kt.academy/book/kotlinessentials) — для начинающих, базовый курс от Marcin Moskała
