# Материалы для обучения

- [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course) - база разработки под Android на Compose
- [Jetpack Compose for Android Developers](https://developer.android.com/courses/jetpack-compose/course) - разработка приложения под Android на Compose, средний уровень
- [Advanced Android with Kotlin](https://www.udacity.com/course/advanced-android-with-kotlin--ud940) - передовые методы и рекомендуемая архитектура для создания Android приложений
