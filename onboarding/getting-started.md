# Знакомство с KMP

Ознакомься с материалами про Kotlin Multiplatform:

С чего лучше начать:

- [Официальный лендинг технологии](https://kotlinlang.org/lp/mobile/)
- [Документация по kotlin multiplatform от JetBrains](https://www.jetbrains.com/help/kotlin-multiplatform-dev/get-started.html)
  - даст представление о том, что такое Kotlin Multiplatform в целом (не только мобильное направление)
  - стоит ознакомиться с 
    - [Базовой структурой проекта](https://www.jetbrains.com/help/kotlin-multiplatform-dev/multiplatform-discover-project.html)
    - [Шаринг кода между платформами](https://www.jetbrains.com/help/kotlin-multiplatform-dev/multiplatform-share-on-platforms.html)
    - [Добавление зависимостей](https://www.jetbrains.com/help/kotlin-multiplatform-dev/multiplatform-add-dependencies.html#dependency-on-a-kotlin-library)
    - [Интеграция с ios](https://www.jetbrains.com/help/kotlin-multiplatform-dev/multiplatform-cocoapods-overview.html)
- [Видео материалы от JetBrains](https://www.youtube.com/watch?v=mdN6P6RI__k&list=PLlFc5cFwUnmy_oVc9YQzjasSNoAk4hk_C)
  - повторять на практике показанное не обязательно - практика будет в следующих шагах
- [Документация - Kotlin Native](https://kotlinlang.org/docs/native-overview.html)
  - даст представление о том, что такое Kotlin/Native

Полезно для практики:

- [Туториал - первое мпп приложение от Jetbrains](https://www.jetbrains.com/help/idea/2024.3/create-your-first-kotlin-app.html#write-code)
